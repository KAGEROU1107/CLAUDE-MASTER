# Source analysis and upgrade rationale
V2 inspected sources: `README.md` (blob 7e3fc606b0d89751b3caf6fe87284b123f3bfa31), `kit/CLAUDE_MASTER_BOOTSTRAP_v2.md` (18ce741c6616f3d8b529980bc4fb6de637649f79), `kit/PROTOCOL.md` (e021648bd01e4970d135c98fcb8177fe2222c02d), `kit/bootstrap.sh` (68014c2d95a5eda115921754780b96e2343e1360), `kit/organizer.sh` (bdddf61b22281f9e7a53ff8f13f42d2444cba78a). Public repository: CLAUDE-MASTER, original V2 revision 8b663cc. Source attribution only.

Findings: V2 hardcodes one person's authority and repository. P0 claims read-only while writing baseline and backup. Protocol forbids outside-root writes while bootstrap copies global configuration. Public/private state not sufficiently separated. Existing shell scripts preview and avoid ordinary overwrites but need symlink/path boundaries, collision and command-failure handling, safer backup/scan, recovery and real testing. Native statusline, hook and skill commands are documented but live runtime was not verified. V2 requires approval after every phase and separates research as a specific late phase, delaying problem recovery. V3 preserves native-first, pacing, safety, source verification, memory, top-20 research and BATON, while adding automatic research and adaptive workphase lifecycle. Default Advanced mode allows safe local updates but protected permissions remain gated.

Design decisions: keep generated private state `.cm-private/`, no public sync; keep installation audit read-only; use on-demand native skills, standard-library helpers and no new dependencies by default; keep numeric limits configurable. Do not introduce twelve subagents or a background service. Retain V2 rather than silently rewrite it. This draft is not runtime compatibility proof.

Continuation analysis: read-only review of two private reference systems informed original generic persona profiles and optional terminal workflow. Their private implementations, identifiers and runtime data are not bundled. Optional terminal workflow fails closed for unmeasured autonomous worker quota; this deliberately differs from ordinary fail-open behavior in one reference. Public upstream Herdr license checked separately. V2 model/effort and pacing tag preserved with explicit unknown fits; critical review holds on unavailable model, effort, or quota.
