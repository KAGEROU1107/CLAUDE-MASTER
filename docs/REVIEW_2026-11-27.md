CI configuration and onboarding documentation. This is a source review with
local Linux execution, not a live Claude Code or Herdr certification.

## Remaining limits

- Real skill discovery, `/clear` → BATON resume, hooks/statusline and Herdr
  detach/reattach still need runtime evidence.
- Windows and the minimum Python 3.9 version were not exercised here.
- Existing ignore rules are not proof that private files are untracked or that
  later negation rules cannot expose them. Follow the documented Git review
  before writing private state.
- Filesystem race resistance and all interrupted/disk-full write paths remain
  outside this test evidence. Use an exclusive trusted workspace.
- The release scan excludes `.git`; it does not certify historical commits,
  license provenance or the privacy of keyed fingerprints.
- No protected persona/canon/plugin promotion, new dependency, or live runtime
  integration was performed by this refinement.
