# Skill routing
Small task: answer/execute directly. New substantial task: analysis → workplan → workphase. Ambiguous material goal: grill. Existing session: baton resume before changing state. Missing technical knowledge: discovery. Failed distinct approaches or repeated identical failure: recovery → discovery → adapt if relevant. Verified fix or explicit correction: learn. Reusable improvement: evolve with authority gate. Important milestone: audit. Waste or budget pressure: optimize. Context gate: baton interrupts new substantial work. Use the smallest relevant skill; avoid calling all skills or invoking recursive subagents. Read procedure when needed; verify runtime discovery. Use native slash commands only if actually available. Missing skill: follow its documented procedure manually, report installation gap. A skill is instructions, not an independent process. No delegated background workers by default.
