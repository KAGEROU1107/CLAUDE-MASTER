# OPTIMIZE

Input: observed overhead and resource signals. Output: measured comparison or explicitly unverified improvement.
Check context, rolling allowance and weekly allowance separately; unknown is not zero. Define three representative tasks and baseline quality/latency/token/cost metrics where observable. Find largest waste: repeated reads, giant auto-loaded files, irrelevant tool outputs, duplicated skills, unnecessary subagents/dependencies, retries. Prefer targeted search, capped outputs, deterministic local scripts, selective memory and on-demand skill loading. Choose smallest adequate model and effort only if supported and user-authorized; do not change settings silently. Split work by budget; preserve quality acceptance criteria. Run same representative tests, compare actual deltas, report measurement limitations. If worse roll back. Never claim subscription bypass or savings without evidence.
Acceptance: quality maintained, cost/overhead evidence or clear unknown, no excess infrastructure or policy weakening.
