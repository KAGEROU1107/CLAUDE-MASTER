# Resource pacing
Use measured context percentage, rolling session allowance and weekly allowance independently. Statusline JSON fields may be absent or null; use only fresh same-session observations or explicit user-reported numbers. Never substitute zero. 60% context: reconcile task state; 70%: prepare verified handover; 80%: no new substantial work, save/read back BATON then ask user to /clear and /baton resume. Session allowance 60%: no heavy work; 80%: checkpoint and pause until actual reset. Weekly allowance 85%: essential work only; ask before heavy tasks. Apply all relevant gates, strongest first. At context+allowance threshold save before pausing; never suggest clear as quota reset. Unknown meter: conservative bounded tasks, checkpoint each milestone, request /context or /usage only when useful. Recheck after large reads and before expensive work. Prefer smallest adequate model/effort when available; never switch provider settings without authorization. Label estimates as estimates; compare fixed tasks before/after. Batch safe independent reads, search before opening, cap outputs, lazy-load modules. No infinite retries or research loops. Budgets are defaults user may change. Stop on real rate-limit errors.
